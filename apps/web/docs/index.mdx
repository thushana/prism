## First-time setup

From the **repo root** (not inside `prism/`):

```bash
git submodule update --init --recursive
pnpm install
# apps/web/.env is created from .env.example by prism generate — edit values there
pnpm run db:push
pnpm run dev
```

## Daily commands (repo root)

| Task             | Command                                   |
| ---------------- | ----------------------------------------- |
| Dev server       | `pnpm run dev`                            |
| Build            | `pnpm run build`                          |
| Lint / typecheck | `pnpm run lint` / `pnpm run typecheck`    |
| Database         | `pnpm run db:push` / `pnpm run db:studio` |
| Align with Prism | `pnpm run prism:sync`                     |
